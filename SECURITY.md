# Security

Namaa keeps your data on your own device and has no server, so most reports are about the app itself: how files are read and written, permissions, and the signed downloads.

## Report a problem

Please report a security issue privately, not in a public issue: open the repository's **Security** tab and choose **Report a vulnerability** (GitHub private advisory). Say what you found, which version, and how to reproduce it. You will get an answer within a few days.

## What counts

- Data loss or corruption when files are moved, copied or restored.
- Reading or writing files outside the app's own folder.
- A download whose signature does not match the fingerprint in the README.

## Supported versions

Only the latest release gets fixes.
