# Contributing to Namaa

Namaa is a small open-source app by [Zimam Labs](https://github.com/zimamlabs). Ideas, bug reports and pull requests are welcome.

## Before you start

- Open an issue first for anything bigger than a small fix, so we agree on the idea.
- Report security problems privately (see [SECURITY.md](SECURITY.md)).

## Pull requests

- `main` is protected: work on a branch, open a pull request, and wait for the **Tests and builds** check to pass. Pull requests are squash merged.
- Name the branch after the change (for example `fix/back-gesture` or `feat/search`); the pull request title is the branch name, and the description says what changed and why.
- Keep a change small and focused, add or update tests for new logic, and update the README and CHANGELOG when behaviour changes.
- Data is plain files. Never write a change that can delete or overwrite a user's files without asking first.
- Build and test with the commands in the [README](README.md#build).
